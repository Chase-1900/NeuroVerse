# 角色 A 功能与验收

以下为产品验收要求。前端已提供示例流程及真实 API 请求封装；真实服务联调与发布验收尚未完成。接口路径除 `/health` 外均省略 `/api/v1` 前缀；字段与状态以 [OpenAPI](../contracts/openapi.yaml) 为准。

| 模块 | 使用流程 | 接口与通过条件 |
| --- | --- | --- |
| P0 A01 首页与导航 | 首页进入宇宙、导入或打开明确标记的示例；导航到档案和导师。 | `POST /sessions`、`GET /graph`。首次建立会话，刷新沿用；首页三卡显示知识、创意和掌握度低于 40 的知识数量，未加载显示 `—`。 |
| P0 A02 三维宇宙 | 旋转、缩放、拖动、点击聚焦、重置；可按标题或摘要搜索、按分类筛选。 | `GET /graph`。星球及关系源自真实数据；详情显示摘要、掌握度和来源；筛选不修改服务端，选择节点高亮相邻关系。 |
| P0 A03 导入与档案 | 确认后上传 TXT/文本型 PDF（最多 10 MB）或粘贴文本（最多 50,000 字符），在档案查看原文。 | `POST /imports` 用 `FormData` 只发 `file` 或 `text`；`GET /jobs/{id}` 每 1.5–3 秒轮询至成功或失败，卸载停轮询，刷新可按已知任务 ID 恢复。成功刷新图谱和 `GET /documents`，按 `GET /documents/{id}` 定位来源切片；失败保留旧图谱，显示 `error.message` 并提供重新提交。 |
| P0 A04 星球管理 | 新增、编辑、删除；删除前确认关联关系将移除。 | `POST /nodes`、`PATCH /nodes/{id}`、`DELETE /nodes/{id}`。保存后刷新，新增后聚焦；删除返回 204 后清理选中及碰撞候选，失败保留表单或原数据。 |
| P0 A05 思想碰撞 | 选择两个不同节点，可取消或替换；生成后显示共同点、标题、描述、行动建议和来源，标注 AI 生成。 | `POST /collisions` 提交 `nodeIds`；`POST /ideas/{id}/save` 保存后重拉图谱，显示暖金创意节点。等待动画不冒充真实进度，重复保存不新增节点。 |
| P0 A06 AI 导师 | 从导师页或节点详情选主题，出题、作答、看反馈并开始下一题。 | `POST /tutor/questions`、`POST /tutor/answers`。显示正误、反馈、正确答案和服务端返回的 `mastery`，据 `reviewNodeIds` 提供推荐；失败保留答案，重试沿用 `questionId`，不重复更新掌握度。 |
| P0 A07 状态与降级 | 空图谱引导导入；网络失败提供重试；低性能或无 WebGL 可切列表继续操作。 | 覆盖 401、502 与离线，不自动模拟结果；验证键盘 Tab、焦点与 Esc、减少动态效果、1440×900、1280×800 和移动端。列表仍可查看、编辑、碰撞和复习。 |
| P1 A08 复习路径 | 逐项查看、跳过或继续，节点删除后从队列移除，队列为空显示本轮结束。 | 只用 `reviewNodeIds` 和现有图谱，不自行评分。 |
| P2 A09 扩展 | 记忆宫殿、手动情绪配色、时间轴和只读分享。 | 各扩展默认关闭；时间轴、分享须等双方确认契约和服务能力。资料不默认共享。 |

## 发布前验证

- 单测：API 映射、渲染副本不污染服务端数据、旧图谱版本不覆盖新版本、删除清理选择、错误映射、掌握度显示。
- E2E：导入 → 探索及核对来源 → 编辑 → 碰撞 → 保存 → 导师 → 刷新保留；另覆盖 401、502、无 WebGL 与失败重试。
- 人工：在 Chrome、Safari 用 100 节点 / 150 条边的固定样例实测，目标约 30 FPS 或更高；检查窄屏面板、键盘和列表降级。超过 100 个可见节点降低标签或粒子负载；超过 250 个节点默认分组或筛选。
- P0 发布门槛：真实 API 联调、lint、单测、E2E、生产构建均实际通过；检查前端产物无真实密钥，并更新运行说明和已知问题。
