# 角色 A 开发规则

- 此目录负责 UI、3D 渲染、交互和前端测试。动手前阅读 [角色 A 原始规范](../NeuroVerse_角色A_AI开发需求规范.md)、[OpenAPI](../contracts/openapi.yaml) 与 [共享图谱样例](../fixtures/graph.json)。按编号落实功能，保留仓库已有约定；不实现或修改 `backend/`。
- API 以 OpenAPI 为准，不更名、不增删字段。遇到文档不一致或现有响应不足，先记录并与角色 B 确认，不发明字段或接口。`GET /health` 无前缀；其余使用 `/api/v1`，除创建会话外使用 Bearer token。GET 不发请求体；204 不解析 JSON。
- `sourceRefs` 是必填数组，无来源用 `[]`；`page` 可为 `null`。新节点发送 `title`、`summary`、`category`，其中 `summary` 可为空字符串。图谱业务状态用字符串 ID，忽略当前会话的旧 `graphVersion` 响应。渲染层在副本上把 `edges` 转成 `links`；坐标留在客户端。
- 401 清理失效 token、当前会话图谱缓存和关联任务状态，提示重新连接，不自动重放写操作。示例模式始终有显著标识，与真实会话数据隔离，真实异常不可伪装成示例成功。
- 真实 AI Key 不进入浏览器、`VITE_*`、源码、日志或构建产物；会话 token 不进 URL、页面显示或日志。导入前说明资料将送交 AI 分析并征得确认。将来源文本和模型输出按纯文本渲染。
- 页面必须是可交互应用，不以视觉参考图冒充界面。WebGL 不可用时保留完整业务操作；主要控件支持键盘，尊重减少动态效果偏好。
- 汇报实际运行的命令、测试结果和未通过事项；仅有示例或静态页面不算 P0 完成。当前提交不编写应用代码。
